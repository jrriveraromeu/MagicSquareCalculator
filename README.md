# MagicSquareCalculator
It is a program that generates a magic square using some of the methods described in _An Introduction to Number Theory, Harold M. Stark 1991_. I used it as a tool for my Number Theory class at Stanford during the summer of 2021. 
It can be run online, without the need to compile it on your computer, in [this](https://replit.com/@jriveraa/MagicSquares?v=1) website.
